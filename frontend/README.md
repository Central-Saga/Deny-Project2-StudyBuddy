# Study Buddy — Frontend (Next.js)

Frontend Next.js untuk **Study Buddy** (dashboard mahasiswa dan administrator). Lihat **[README proyek](../README.md)** untuk langkah instalasi lengkap menggunakan Docker Compose.

- Halaman login: http://localhost:3000/login
- Halaman admin: http://localhost:3000/admin (memerlukan login admin)
- Base URL API: `/api/v1`, melalui rewrite pada `next.config.ts`.
- Untuk Docker, gunakan `.env` di **root repository**. File `.env.example` di folder ini hanya referensi.
