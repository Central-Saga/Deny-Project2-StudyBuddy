# Study Buddy — Backend (Laravel API)

Backend Laravel untuk aplikasi **Study Buddy**. Dokumentasi utama, cara menjalankan melalui Docker Compose, konfigurasi `.env`, akun demo, dan pengujian ada di **[README proyek](../README.md)**.

- API utama: `/api/v1`.
- Konfigurasi Docker: `.env` di **root repository**, diteruskan ke container backend.
- Seeder: `database/seeders/DatabaseSeeder.php`.
- Test: `docker compose exec backend php artisan test` (lihat langkah membuat database test di README utama).
